# Multicolored Julia Set Fractal

A Python implementation of a Julia Set fractal — an animated, multicolored
visual composition built from a simple recursive mathematical rule.

Created for the BS(CS) fractal design lab: demonstrates recursion/iteration,
self-similarity, and a creative visual treatment (color cycling + animation)
applied to a classic fractal algorithm.

## What is a Julia Set?

A Julia Set is generated by repeatedly applying the same rule to a complex
number:

```
z(n+1) = z(n)^2 + c
```

- `z` starts out as the pixel's own coordinate on the complex plane.
- `c` is a single fixed complex number, shared by every pixel in the image.
- We iterate the formula for each pixel and check whether `|z|` ever grows
  past 2. If it does, the point "escapes" to infinity; the number of
  iterations it took to escape is used to color that pixel.
- Points that never escape belong to the Julia Set itself and are colored
  black.

This "escape time" coloring is what produces the swirling, self-similar
contour bands typical of these fractals. Because Julia Sets are extremely
sensitive to the value of `c`, slowly moving `c` in small steps makes the
whole fractal shape continuously morph — which is how the animated versions
below get their motion.

## Files in this project

| File | What it does | How to run it |
|---|---|---|
| `julia_fractal_static.py` | Renders **one** high-resolution (1200x1200) multicolored frame and saves it as `julia_fractal.png`. | `python julia_fractal_static.py` |
| `animated_julia_fractal.py` | Desktop version: opens a live, looping animated window where the fractal shape morphs and the colors flow. Can optionally export a `.gif`. | `python animated_julia_fractal.py` |
| `julia_fractal_colab.py` | Google Colab version of the animation: paste the whole file into one Colab cell and run it — renders inline as an interactive HTML5 player (play/pause/step), no popup window needed. | Paste into a Colab cell, press Shift+Enter |

All three share the same core fractal math (`compute_julia_escape_grid`) and
the same HSV-based multicolor scheme (`escape_grid_to_rgb`); they only differ
in how the result is displayed or animated.

## How the color and motion are achieved

- **Multicolor:** escape-time values are mapped through a cycling HSV
  (Hue-Saturation-Value) color wheel instead of a flat grayscale, so contour
  bands come out as vivid rainbow rings rather than shades of one color.
- **Motion (animated versions only):** the parameter `c` is walked slowly
  around a small circle in the complex plane, one step per frame — this
  morphs the fractal's shape continuously. The hue wheel is also rotated a
  little each frame, making the colors appear to ripple across the fractal
  as it animates.

## Key configuration constants

Each script exposes a small set of constants near the top that are safe to
tweak:

- `WIDTH`, `HEIGHT` — output resolution in pixels.
- `MAX_ITER` — how many iterations to try before giving up on a point
  (higher = more detail, but slower).
- `ZOOM` — how zoomed-in the view is (smaller = more zoomed in).
- `C_RADIUS` / `C_ANGLE` (static) or `C_RADIUS` (animated) — controls which
  family of Julia Set shapes you get.
- `N_FRAMES` (animated versions only) — number of frames in the animation
  loop.

## Core CS concepts demonstrated

- **Recursion / iteration** — the `z = z^2 + c` update rule applied
  repeatedly per pixel.
- **Self-similarity** — zooming into any region of the fractal reveals
  similarly structured detail.
- **Vectorized computation** — NumPy updates the entire pixel grid at once
  per iteration instead of looping over pixels one at a time in Python,
  which is dramatically faster.
- **Creative design** — an escape-time algorithm (a purely technical/
  mathematical exercise) is turned into a visual composition through color
  cycling and an animated parameter.
